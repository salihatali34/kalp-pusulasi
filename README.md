# Kalp Pusulası

Başlangıç prototipi: hazır test kataloğu ve “Beni ne kadar iyi tanıyorsun?” için cevap seçme, paylaşım linki üretme ve puanlama akışı.

## Açma

`index.html` dosyasını tarayıcıda açarak önizleyebilirsin. VS Code'da düzenlemek için bu klasörü açıp `index.html` dosyasını seç.

Bu prototip harici servis veya sunucu kullanmaz. Başka cihazlarla gerçek bağlantı paylaşımı ve cevap anahtarını güvenli saklamak için yayınlama aşamasında sunucu eklememiz gerekecek.
